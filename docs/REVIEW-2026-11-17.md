## PY32 (fw/)
- [x] H1 zero-cross glitch accepted once locked (>7.1 ms) → mid-cycle turn-on. Window ±8 % around
      the expected edge; earlier = noise (ignored), later = relock (no output until locked).
- [x] H2 Zigbee/button off during a momentary hold, release before the fade ends → light stays lit
      while "off". hold_stop only when holding; hold_end applies when off. Also end holds on
      switch-type change and on/off writes (L).
- [x] H3 SIM build could be embedded/pushed: header flag (reserved[0] bit0 = SIM) set by the build,
      mkimage warns, embed_ztu refuses, ZTU refuses; SIM runtime guard: real PA4 edges → outputs off.
- [x] H5 endless rewrite after BAD_IMAGE/FLASH: flash_write_page skips identical pages (no erase).
- [x] M1 power-up self toggle: SysTick IRQ before controls_init + slow store_load (3.3 ms > press).
      Enable tick IRQ after controls_init, clear the ring, baseline after ~30 ms settle.
- [x] M2 update = power cut: flush pending save, put on/level in mailbox reserved words, restore after
      the update (also after the bootloader's 10 s give-up). Mailbox xor-bound magic.
- [x] M5 IWDG ~1 s in the app; bootloader refreshes it (IWDG survives software reset).
- [x] M6 save window: not while acquiring lock; one page attempt per window (no 10 ms double stall).
- [x] M7 press 20 ms steady low (user); HOLD only when no release is pending (run == 0).
- [x] L rejected DP writes: ack with current value; min/max sibling reported; switch_type 0..2;
      RX buffer full → parse before dropping; soft start after a short dropout (gap path zero current).
